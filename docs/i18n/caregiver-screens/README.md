# Caregiver screens in Hindi (Round 2 batch 5b)

A fresh demo account with the caregiver's screen language set to हिन्दी (Account → Language for your
screens). Headless Chrome, reduced motion, demo banner removed; 1280 × 900 unless the name says 375.
The demo elders' names, reminder titles and family notes are typed text and stay as typed.
