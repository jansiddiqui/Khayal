# Games v2 screens (375 × 812)

Taken with headless Chrome at 375 × 812 with reduced motion, on a fresh demo patient. Levels were
raised through the API with perfect sessions to show later boards. On every game screen the whole
board and every answer or commit button are visible without scrolling (measured: page height = 812).
